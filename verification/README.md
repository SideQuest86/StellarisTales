## Limits

This archive does not simulate save state or every engine condition. Perspectives compile symbolic compatibility, nested text composition and switch branches, with bounded expansions for exceptionally complex scripts. Unlabelled state-dependent passages use numbered readings. Exact source remains in the developer data layer, without a reader code entry point.

Origin family rules use explicit source ranges and source identities. General stories use graph grouping and can benefit from editorial refinement. Three source localization keys are missing per language; coverage.json records them. Placeholder names are normalized. No Wiki commentary was fabricated after HTTP 403.

Older browser-results.json, performance.json, online-results.json and non-v2 captures are historical Draft 1 evidence.

Eight category audits and complete browser traversals are in categories/. Run node scripts/audit-categories.mjs for every dossier and node scripts/verify-category.mjs CATEGORY for each representative. Solid tree links retain parsed game relations; dashed links provide reading coverage without asserting game causality. Closed uniform covers and opened event art are asserted by the main browser verifier.
