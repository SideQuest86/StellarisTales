## Fine, keep (checked in the built site)

- Header, categories, `{n} 份` counts, scene fallback, GPU notice (windows/flag steps are genuinely actionable).
- Continue box: `继续阅读` + `强制重置 · 胜利是我们的` + `重新开始` / `Continue reading` + `Hard Reset · Victory is Ours` + `Start over`. Clear and short.
- Choice cards (`你的选择` / `Your choices`, `故事继续`) with condition captions such as `仅在以下情形出现：唯心主义`; these are meaningful conditions. Choice preview of consequences under a selected option is intentional.
- `以下结果互斥，只会发生其一` / `Only one of these outcomes happens`; `随机结果 · 基础约50%`; delay captions `约100–120天后`.
- Review/non-canon disclosure strings (`审阅注释 · 非游戏原文`, 3D `非官方三维诠释…`): required provenance.
- Map legend, zoom/fit/locate controls, `map.viewport` aria text, audio controls (`原声列表`, `专辑循环播放`), museum 3D controls (`三维模型 / 原版图像 / 复位`, aria `拖动旋转，滚轮或 +/- 缩放…`).
- Search placeholders and `没有匹配结果。` text itself; museum filters `全部展区` / `全部稀有度`; type labels `标本` / `效果`.
- Mobile 390 px: no wording overflow found in landing, reader, search, museum, exhibit, playlist (toolbar shows icons only; text wraps cleanly).
- Game text, effect tooltips marked `gameText`, name-fill output (`这个名字` / `this name`, `他们` / `they`) left as shipped.
