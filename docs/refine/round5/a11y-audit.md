## What passes (measured)
- Accessible names: all buttons, links, inputs, selects and summaries have names in zh and en on archive, reader (toolbar, choices, 3 continue/next cards, Back/Start over, profile controls, map controls, 13 map nodes), search, museum (list, chips, exhibits, 3D toggle/reset), player (prev/play/next/seek/volume/playlist), GPU notice (Dismiss, summary). Exceptions are #1 and #2 only. Next-chapter picture cards use `alt=""` (decorative, text duplicates) and the album cover has a translated alt.
- Dialog semantics: search uses native `<dialog>` + `showModal` (labelledby `search-title`, Tab stays inside, Esc closes, focus returns to `#search-open`, count is `role=status`). Museum root is `role=dialog aria-modal=true` with name (zh/en), Tab trap verified over 60 presses, Esc closes exhibit then museum; focus returns to the exhibit tile, then to `#museum-open`. Playlist Esc closes and keeps focus on its toggle (`aria-expanded` kept in sync, `aria-current` on the current track).
- Reader: `#reader` is `section[aria-labelledby]`; archive HUD and category nav become `inert` while open; focus moves to `h1#reader-title`; closing returns focus to `#open-story`; Esc closes.
- Keyboard-only journey (en, cetana, Tab + Enter only): open story, choose (aria-expanded toggles, response revealed), continue to next chapter (focus to new title), repeat, Back (focus to title of previous chapter). Not exercised: specimen link -> exhibit -> return (cetana had no `.specimen-links`; museum open/Esc/return itself verified).
- Landmarks: header, nav (named), main, footer, aside (named), dialog, regions; `html lang` follows zh-CN/en; mixed zh+en blocks in zh mode all carry `lang=en`.
- Focus visibility: global `:focus-visible` 2px gold outline (`style.css:118`), measured 2px solid #d8bb84 on choices and buttons.
- Contrast: 73 unique element/class combinations measured over archive, reader, profile, fx, search, museum, playlist (contrast-all.json); all >= 4.5:1 except #4 and #5. Examples: ink 12:1, dim `#86a29f` 6.35-6.78, faint `#6f8b88` 5.05 (10px chip counts), gold summary 6.3, player artist 5.07, GPU adapter 11px 4.73, code 6.2. Text over images and the WebGL scene is not measurable by computed style.
- Reduced motion: system and site toggle honoured (existing check); canvas frame hash identical across 1.5s in both settings so no motion regression found.
- Responsive: 375px phone, 640px (200%) and 320px (400%): no horizontal page scroll in archive or reader; phone touch targets otherwise >= 32px (chips 44px, exhibit tiles large).
- Forced colors: text, buttons, search, museum, reader and player remain legible (screenshots forced-*.png); system focus colours apply to default outlines.
- Toast: `#toast role=status` is always in the DOM, so message changes are announced.
- GPU notice: `aside` named, Dismiss labelled, details/summary native.

## Caveats
Live site fonts load from Google Fonts (may differ from local); headless Chrome has no real screen reader, so announcements are inferred from AX tree/roles. Contrast was computed against the nearest opaque ancestor background (blended with alpha and opacity), not image backdrops.
