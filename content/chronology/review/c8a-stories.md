   the real one (e.g. `shroud.4199` is reported at events/shroud_events.txt:11613 but is at 9255; shroud.4811 reported
   14953, real 11619). Doc `source.line`, `callers.py` output and `print-tree` sources are affected. c8a evidence uses
   real line numbers. Fix: map offsets back to the original file (or record the line before expansion).
2. **`base = <event>` inheritance is not modelled.** Events such as shroud.6851/6852/6853 (`base = shroud.4205`, no
   `option_clear`) inherit their parent's title, picture and options in game, but the extracted records have no options and
   an empty title. Same pattern: all Mindwarden menu sub-pages (title inherited from 4205), shroud.3001-3003 etc.
   (`base = shroud.3`). Worked around with notes/bridges in `event-shroud-4199`.
3. **Breadth-first capture by earlier entries.** `build_story.place_entry` expands each entry immediately, so a bridge or
   return option from an earlier entry captures a later root entry as its child (seen with exclusive greeting entries of a
   communication hub). Suggest: place all root entries first, then expand. c8a avoided bridges that would trigger it.
