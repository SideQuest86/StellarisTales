# 灰蛊 / Gray Goo

- 分类 Category：深空异闻 Exploration · DLC：《遥远繁星》Distant Stars（has_distar）

## 如何开始 How it starts

需要《遥远繁星》。冷荒芜或冰冻星球可能生成（4级，权重1，每个帝国一次）。

Requires Distant Stars. Can spawn on cold barren or frozen planets (level 4, weight 1, once per empire).

## 剧情脉络 Story outline

distar.40“灰蛊”：星球表面的灰色物质由数十亿纳米机器人构成，它们曾失控复制并吞没了整颗星球。依次给予未拥有的科技：装配模式 → 建造模板 → 可重复的建造时间缩减；记录标本 nanite_sludge。若帝国正在进行“L星团”事件链（l_cluster_chain，需《遥远繁星》），结果增加一条线索（共需7条）；集齐时触发 distar.10904“L星门见解汇集”（另一故事）。

distar.40 "Gray Goo": the grey coating is billions of nanites that once replicated out of control and engulfed the planet. Grants the first missing tech of assembly pattern → construction templates → repeatable building-time reduction; specimen nanite_sludge. If the empire is running the L-Cluster event chain (l_cluster_chain, Distant Stars), the result adds one clue (7 needed); completing the count fires distar.10904 "L-Gate Insights Gathered" (a separate story).
