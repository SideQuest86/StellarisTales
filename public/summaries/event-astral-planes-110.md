# 星界行动 / Astral Actions

- 分类 Category：星界裂隙 Astral rifts (C4) · DLC：星界位面 Astral Planes

## 如何开始 How it starts

科技增长时（`on_tech_increased`）检查：刚研究出的科技是“星界采集”（`tech_astral_harvesting`），且国家不是裂隙世界起源，也不是已赢得宇宙创生危机的国家。

On any tech increase (`on_tech_increased`): the technology just researched is `tech_astral_harvesting`, and the country is neither Riftworld-origin nor a winner of the Cosmogenesis crisis.

## 剧情脉络 Story outline

单个通知事件（选项“很迷人”），说明已解锁星界丝缕的采集与星界行动，是玩家理解这种稀有资源的入口。没有后续事件。

A single notice event (option “Fascinating”) explaining that gathering and containing astral threads has been unlocked and that astral actions can use them. No follow-up event.
