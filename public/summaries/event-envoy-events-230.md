# 特使被捕 / Envoy Arrested
- 分类 Category：C8 银河轶事 / Galactic miscellany

## 如何开始 How it starts

领袖被指派为特使时（on_leader_assigned），若他是在驻在国犯事后逃亡的特使（envoy_events.225 选项B 设下的旗标 fugitive_envoy@驻在国），且被派去的恰是那个国家。

Triggered when a leader is assigned as an envoy (on_leader_assigned) who is a fugitive from the host country (the flag fugitive_envoy@country set by envoy_events.225 option B) and is posted to that very country.

## 剧情脉络 Story outline

特使被驻在国逮捕。唯一选项“就这样吧”：特使被清除；花30影响力，否则3600天的“外交使团是个笑话”修正。

The ambassador is arrested by the host country. Single option "So be it": the envoy is removed; costs 30 influence, otherwise the 3600-day "diplomatic corps is a joke" modifier.
