# 宇宙黎明 / Cosmic Dawn

- 分类 Category：起源 Origins · DLC：Infernals Species Pack

## 如何开始 How it starts

开局时母星被设为火山世界：大部分居民处于休眠舱（5 个休眠舱矿藏），infernals.10 在 1 天后触发 infernals.2500“深处的信号”。
At start the homeworld is volcanic with most of its people in stasis pods; infernals.10 fires infernals.2500 *Signals in the Deep* after one day.

## 剧情脉络 Story outline

1. **钻探**：2500 → 项目“钻探地壳”→ 2505“更多族人苏醒”：选择方针开始局势“深挖”。 2500 -> Drilling the Crust -> 2505 starts the situation Deep Excavation.
2. **局势阶段**：2510“失忆与数据”→ 2515“生命维持失败”（选择人才或增加舱位；4 个月后 2520“星际避难所”开启异常事件链）→ 2540“远古监狱”（强攻 2545 / 贿赂 2550）→ 2555“悲剧事故”（2560 / 2565 / 2570 / 2575）→ 完成时 2580“我们的历史显现”。
   **Stages**: 2510 -> 2515 (2520 starts the anomaly chain 4 months later) -> 2540 (2545 / 2550) -> 2555 (2560-2575) -> 2580.
3. **沉睡者异常**：孤立的沉睡者（2525）、警惕的沉睡者（2530 → 2 年后 2531“归来”）、沉睡者的星港（2535）。 Sleeper anomalies 2525 / 2530 (-> 2531) / 2535.

## 分支与结局 Branches and outcomes

- 2545 / 2550 互斥；2555 的四个选项各一窗口。结局：2580。 2545 / 2550 are exclusive; four windows for 2555; ending 2580.
