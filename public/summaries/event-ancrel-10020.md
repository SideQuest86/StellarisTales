# 研究民用方面的应用 / Find Peaceful Applications

- 分类 Category：先驱者与考古 Precursors · DLC：《远古遗物》Ancient Relics

## 如何开始 How it starts

稀有文物行动“研究民用方面的应用”（artifact_find_peaceful_applications，common/artifact_actions/artifact_actions.txt:408）：需要 tech_arcane_deciphering，花费150稀有文物，之后有900天冷却（与军事版共用）；触发 ancrel.10020。

The artifact action "Find Peaceful Applications" (artifact_find_peaceful_applications, common/artifact_actions/artifact_actions.txt:408): needs tech_arcane_deciphering, costs 150 minor artifacts, then the 900-day cooldown shared with the military version; it fires ancrel.10020.

## 剧情脉络 Story outline

ancrel.10020 “我们该聚焦哪一方面？”按帝国类型给出的互斥选择，各自带一个持续1800天的修正：古代风潮（愉悦生物）、高效制造（消费品）、电池小型化（舒适度）/ 高效维护（蜂群）/ 电池小型化（机器）、管理见解 / 信息素增强（蜂群）/ 算法精炼（机器）（领袖改良）；“算了”则退还50稀有文物并移除冷却。

ancrel.10020 "What aspect shall we focus on?" Exclusive choices shown by empire type, each a 1800-day modifier: Ancient Fad (happy organics), Efficient Manufacturing (consumer goods), Battery Miniaturization (amenities) / Efficient Maintenance (hive) / Battery Miniaturization (machine), Management Insights / Pheromone Enhancement (hive) / Algorithm Refinement (machine) (leader improvements); "Actually, never mind" refunds 50 minor artifacts and removes the cooldown.

## 分支与结局 Branches and outcomes

- 同一类别按文明类型有三个版本（普通、蜂群、机器），同时只显示适合者。 / Each category exists in three versions (regular, hive, machine) and only the one that fits is shown.

## 条件与文明差异 Conditions and variants

- 各选项的显示条件按文明类型而异。 / Option visibility depends on empire type.
