# 受到冒犯 / Offense Taken

- 分类 Category：C8 银河轶事 / Galactic miscellany

## 如何开始 How it starts

Galactic Community 特使的随机事件：五年脉冲（action.2211）的负面列表 on_five_year_random_pulse_country_negative_list，权重见分支栏（common/on_actions/00_on_actions.txt:576-592）；on_action 会先检查事件触发条件、不满足的从列表中剔除，所以只要有一个能触发就必有一个触发。通常共用5400天的 recent_envoy_event 冷却。 本事件：特使驻在某国，一段私下谈话泄露冒犯了某方；无 recent_envoy_event；权重10/180。

A random Galactic Community envoy event: the negative list of the five-year pulse (action.2211), on_five_year_random_pulse_country_negative_list, weights in the branches (common/on_actions/00_on_actions.txt:576-592); on_actions check each event's trigger first and drop the failing ones, so as long as any can fire one always does. Most share a 5400-day recent_envoy_event cooldown. This event: An envoy whose leaked private conversation offended a party; no recent_envoy_event; weight 10 of 180.

Option one: keep the envoy (the offended party's opinion modifier opinion_envoy_insult_taken; xenophobes / homicidal empires also gain monthly unity); option two: recall for retraining (punishment cooldown).
