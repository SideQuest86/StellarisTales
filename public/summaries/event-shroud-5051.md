# 代理人战争准备遭曝光 / Proxy Warmongering Revealed

- 分类 Category：C8 银河轶事 / Galactic miscellany

## 如何开始 How it starts

代理人战争开始时（on_proxy_war_started → 5050），每有一个进攻方，煽动者就有10%几率被标记为“败露”。当这场代理人战争真正打响（on_war_beginning → 5051）且煽动者已败露时触发。

When a proxy war starts (on_proxy_war_started → 5050) the instigator has a 10% chance per attacker to be marked "busted". When the proxy war actually begins (on_war_beginning → 5051) with a busted instigator, this fires.

## 剧情脉络 Story outline

7天后：被卷入的一方收到 5055（获得对煽动者的负面看法），煽动者收到 5060（若为星海共同体成员，得到十年的负面修正）。

7 days later the involved country gets 5055 (negative opinion of the instigator) and the instigator gets 5060 (a 10-year negative modifier if a Galactic Community member).

## 分支与结局 Branches and outcomes

两个窗口是同一事件对不同帝国的通知，并行而非互斥。

The two windows are notices of the same event to different empires — parallel, not exclusive.

## 条件与文明差异 Conditions and variants

两者正文按是否星海共同体成员变化。

Both texts vary by Galactic Community membership.
