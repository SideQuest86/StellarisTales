2500 -> project "Drill through the crust" -> 2505 "More kin awake" (authorise full excavation / only what is needed / outsource) -> situation "Deep Excavation" -> stage events 2510 Amnesia and Data -> 2515 Life Support Failure -> 2540 Ancient Prison -> storm (project -> 2545) or bribe (project -> 2550) -> 2555 Tragic Accident (four responses, 2560/2565/2570/2575 seven days later); 2515 also leads four months later to 2520 "Stellar Refuge", starting the event chain "Stellar Refuge".
