  The observed pre-FTL civilization's tech-progress situation has a 5/100 monthly chance to run preftl.50 (then an 1800-day cooldown), which draws one valid event from the monthly observation pool by weight; this event has weight 100. - 隐藏分派事件设置一次性标记，然后在 0–25 天后向观测哨站拥有者（及游牧中继站观察者）发出可见事件。
