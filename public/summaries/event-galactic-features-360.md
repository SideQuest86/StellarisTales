# 恶臭的后代 / Effluvial Offspring

- 分类 Category：C8 银河轶事 / Galactic miscellany

## 如何开始 How it starts

虚空云（cloud 类国家）连续摧毁两支舰队时，云的强度达到2，galactic_features.360 以25%×4概率生出一支新的“流出后代”（四种名字之一），并通知有通讯的人类玩家。

When a Void Cloud fleet destroys two fleets its strength reaches 2 and galactic_features.360 spawns a new "Effluvial Offspring" fleet (one of four names, 25% each) and informs human players in contact.

## 剧情脉络 Story outline

通知窗口 galactic_features.361，选项依伦理而异（狂热和平者/平衡/军国/排外或终结者/亲外/…/灵性/唯物）。

The notice galactic_features.361 has options by ethic (fanatic pacifist / balanced / militarist / xenophobe or terminator / xenophile / ... / spiritualist / materialist).
