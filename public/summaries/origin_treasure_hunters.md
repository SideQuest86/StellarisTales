# 寻宝猎人：星图、海盗与奈斯的遗产

> 含主线结局。这是人工审读笔记与故事导读，不是原版正文。主线路径已核对多段原版脚本；月度插曲、部分展示事件和跨章节视角仍未全部验收。

## 故事概述

冒险从母星发现的远古胶囊开始。解开其中的星图后，玩家追随隐藏星系、海盗与遗迹中的线索，不断补全星国图志。它不仅指向奈斯船长的财富，也是开启宝库的钥匙。

追寻并非一连串自动出现的报告：科研、调查、舰队进入星系、击败敌舰、修复星门分别推动不同阶段。黑针势力既是障碍，也提供了一个真正结束冒险的交易机会。若接受报酬交出星图，故事在交易中结束；若继续争夺，则要解决其舰队和破坏网络，才能进入宝库。

宝库中等待玩家的除了财富，还有以机械形态存在的奈斯本人。她曾是海盗女王。最后的抉择转向如何分配财富、如何对待她，以及自己的文明将留下怎样的名声。结尾没有另一张星图替玩家决定未来。

## 按正常游玩顺序追踪主线

1. 远古胶囊研究：8000 → 初始胶囊项目 → 8005 → 8015。此处才是故事开场。
2. 舰队进入标记星系：8020 → 与胡船长对话8025。结束通讯后才进入敌对阶段，击败对应舰船后进入8045。
3. 调查遗骸并研究第二份胶囊：取得下一片星图，8060生成海盗基地所在星系。调查或取得该星系后进入8100。
4. 基地可以轰击、登陆或潜入。潜入的成功8115与失败8120互为替代；失败并不等于整条寻宝故事终结。轰击增援插曲也不能冒充基地最终结果。
5. 解码第三片星图后定位下一处地点，8200 → 8205对话 → 8210建立考古遗址。考古进程8220 → 8225 → 8230。
6. 回到目标星系与伊纳克斯交涉8245。击败对应舰船后取得第三片星图项目，再研究第四个胶囊，最终定位星门。
7. 消灭守门虚空虫后，按已有科技与星门状态继续：研究星门启动科技、修复或激活星门，或进入已恢复的星门阶段。这些不是人人必做的三个连续步骤。
8. 舰队进入宝藏所在星系，8405 → 8410对话 → 8415决定是否与黑针交易。
9. 接受交易进入8500并结束此路线；拒绝则进入8505破坏网络局势及军事对抗。
10. 击败黑针并进入8560后，完成奈斯宝库项目 → 8565 → 8570对话 → 8575分配宝藏 → 30天后8580处置奈斯。
11. 8580之后30天进入8600主线收尾。部分选择在此前或多年后有附加回应，详见下节。

## 重要分支与时间关系

### 基地与对话

基地潜入与直接掠夺会改变后来伊纳克斯的开场文本。这个区别来自过去的行为，不能把两段文本同时呈现为一次会面。胡船长、黑针和奈斯的提问也有各自的解锁规则；一些问题可重复，一些问完后消失，关闭通讯并不总要求问完全部问题。

### 乙特遗产与展览支线

8055找到的胶囊同时保存了乙特文明遗物和一张字条。字条称，盗来的巨像意外毁灭了这个前超光速文明，请后来者保存他们的记忆。这是字条所述的事故经过，不应改写为玩家亲历的事件。

胶囊研究主线之外，8070按此前是否提出档案馆计划分派8075或8076；8075另要求尚未掌握银河档案学。8075可选择支付500能量币取得50%科技进度，也可拒绝支付，两种选择之后都开启展览项目。不能将付款写成展览的必要条件。

展览项目消耗3000工程研究，没有期限，完成后8080建立精密保存设备，保护易损的乙特标本。若尚未掌握银河档案学，获得25%科技进度；否则获得物理研究奖励，并获得展览改善修正。这是保存遗产的可选插曲，不是开启第二个胶囊研究的前置。

### 破坏网络的处置

局势从25进度开始。达到100时，若存在符合条件的非统治者、非继承人、非节点领袖，可触发8520叛徒处置；不存在符合条件的领袖时不能把它设为必经章节。

处决与重新教育按机械、蜂巢或其他帝国给出不同结果。第三种处置仅向非格式塔开放，其死亡与获救结果由随机分派决定，不会先后都发生。处置叛徒并不终结局势。

进度达到150进入8550；应对失败进入8545。这两者仍可能需要击败敌舰，不能分别冒充整个故事的胜利或失败结局。若在局势仍进行时击败黑针舰队，则进入8555并终止局势，继而通向8560。

### 局势中的周期性袭击

8509/8620负责准备可被破坏的目标，分别针对定居帝国的星系与游牧帝国的驿站；它们不是有独立正文的故事章节。8510/8625在没有生成阻断和击毁舰队冷却时选择目标，安排120–210天后的8515检查。

8515仍要求局势存在、目标标记和归属或相关驿站/方舟条件有效，而且没有击毁冷却。满足这些条件后，才在25权重生成破坏舰队与75权重不生成之间抽取结果。因此不能把它解释为“每月25%必定掷一次”，也不能将多次袭击排列为固定主线。局势结束后，已排定的回调也不会无条件继续生成舰队。

### 袭击舰队与主舰队

袭击舰队和决定主线胜负的黑针主舰队使用不同标记。create_sabotage_fleet生成的袭击舰队带sabotage_situation_fleet标记；击毁后8516清理目标标记，并将对应帝国的生成冷却重置为3600天。它不会推进到8555，也不直接解锁宝藏。

8540检查的是black_needle_fleet及对应寻宝帝国的is_spawned_for标记：局势仍在进行则进入8555；否则若黑针特殊项目存在，完成该项目；再否则进入8560。击败任意一支名称叫“黑针”的舰队并不足以满足这些条件。

### 宝库中的最后选择

8580中的拒绝在1天后触发8585告别；审判在1天后触发8590回应。无论这些附加回应如何，主线收尾8600由8580独立安排在30天后发生。

审判还有8595，发生在8590之后1800–3600天。正确阅读节奏应先经过8600，再读这段远期后日谈。没有选择审判的路线不应出现它。回到较早节点改选时，也不能因“以前读过审判”而保留这条路线。
