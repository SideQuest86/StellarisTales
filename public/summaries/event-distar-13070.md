## 如何开始 How it starts

on_system_survey：国家获得某星系的勘测状态但并非由科学船亲自勘测，该星系带标志 abandoned_gateway 并有 gateway_ruined 巨型建筑，国家尚无 encountered_first_gateway 标志。

on_system_survey: a country gains surveyed status of a system without a science ship, the system has the star flag abandoned_gateway and a gateway_ruined megastructure, and the country does not yet have encountered_first_gateway.

Single event distar.13070 "Abandoned Gateway": saves the gateway system (gateway_system), sets encountered_first_gateway and records the gateway bypass type as seen; it reuses apoc.1's text (a different body if an L-Gate was seen before) and the only option has no further effect.
