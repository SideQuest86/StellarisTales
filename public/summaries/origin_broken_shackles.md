# 粉碎的枷锁 / Broken Shackles

- 分类 Category：起源 Origins · DLC：First Contact

## 如何开始 How it starts

开局隐藏事件 origin.110 创建坠毁奴隶船遗址（建造首艘科研船、隐藏事件5060后才可见）；议会制或传媒集团另有 5041“脱枷之后的政治局面”。
At game start hidden origin.110 creates the crashed slaver ship site (visible only after the first science ship, hidden 5060); Parliamentary or Media Conglomerate empires also get 5041.

1. **遗址与母星**：遗址阶段 5015 → 5020 → 5025 → 5030 → 5035 → 项目“定位母星”→ 5040 → 事件链“寻找家园”：勘测主母星系（5000）、其他被掳走族群的母星（5001/5009），三处找到后 5270“重返归根之地”。5000 之后还有思乡线 5002–5008。
   **Site and home worlds**: stages 5015-5035 -> project Locate Home Worlds -> 5040 -> the Finding Home chain: survey the main system (5000) and other abductee worlds (5001/5009); with all three found, 5270. After 5000 the homesick line 5002-5008 follows.
2. **自由的代价**（游戏中期）：5046 → 放任（5200 → 5210 → 5225/5230/5235 或 5215/5220）或特别委员会项目（5205 → 5240/5245/5250 …）。
   **The Cost of Freedom** (mid-game): 5046 -> let it run (5200 -> 5210 ...) or the committee project (5205 ...).
3. **MSI**：首次接触 5065 → 5070 → 5075；星海共同体相遇 5080；奴隶制议案 5094–5131；开战公告 5135/5146/5147，战果 5140/5142/5145；联邦 5150/5151 → 和解 5276。
   **MSI**: first contact 5065 -> 5070 -> 5075; Galactic Community 5080; slavery resolutions 5094-5131; war announcements 5135/5146/5147, outcomes 5140/5142/5145; federation 5150/5151 -> reconciliation 5276.

## 分支与结局 Branches and outcomes

- 议案各为通过/未通过二选一；战争结果三选一。 Resolutions pass or fail; the war has three outcomes.
- 3种分裂结局 5225/5230/5235 各1/3，随后 5255。 Three divided-society outcomes (1/3 each), then 5255.
