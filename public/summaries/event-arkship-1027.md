# 修复计划 / Recovery Project

- 分类 Category：C8 银河轶事 / C8 Galactic miscellany · DLC: Nomads

## 如何开始 How it starts

方舟舰或驿站瘫痪后，arkship.1027 为前来救援的游牧帝国开启特殊项目“修复计划”（RECOVER_DISABLED_NOMAD_VESSEL）。

When an arkship or waystation is disabled, arkship.1027 enables the special project Recovery Project (RECOVER_DISABLED_NOMAD_VESSEL) for the rescuing nomad empire.

## 剧情脉络 Story outline

需要后勤船或方舟舰到场，90天工程研究，1800天内完成；完成后由项目效果修复该舰（没有另外的事件窗口）。

It needs a logistic ship or arkship on site, 90 days of engineering research, within 1800 days; completion repairs the vessel through the project effect (no separate event window).

## 分支与结局 Branches and outcomes

只有项目本身；超时失败。

Only the project itself; it fails on timeout.
