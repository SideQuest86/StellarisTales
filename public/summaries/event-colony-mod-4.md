# 观测到彗星经过行星环带 / Comet Sighted Through Belt

- 分类 Category：文明纪事 Society (C7) · 星球修正殖民地事件 planet-modifier colony event

## 如何开始 How it starts

殖民地满一年时，隐藏分派器 colony_mod.161 发现星球带有“小行星带”修正、没有“发现彗星”修正，所有者不是格式塔，且排在前面的磁场、辐照、泰坦巨兽、地震事件都不适用，则 30–120 天后触发本事件。

At the first anniversary the dispatcher fires this event 30–120 days later on a world with *Asteroid Belt* and no *Comet Sighted*, for non-gestalt owners, if no higher-priority modifier event applies.
