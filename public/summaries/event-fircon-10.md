# 观测洞见 / Observation Insights

- 分类 Category：文明纪事 Society (C7)

## 如何开始 How it starts

- 每月“增加前超光速洞察”隐藏事件（fircon.10，00_on_actions.txt:120）：当至少一个帝国有观测站且其边境内有觉察度不满100的前超光速文明时，为其启动“观测洞察”局势。
  The monthly "adds pre-FTL insights" hidden event (fircon.10, 00_on_actions.txt:120): if an empire has an observation post and pre-FTL civilizations with awareness below 100 within its borders, it starts the "Observation Insights" situation.

## 剧情脉络 Story outline

- 局势「观测洞察」只有一个阶段（0–100）：每月进度来自 observation_post_insight（被动观察0.5，其他任务1.0，每个被观测文明），受亲外/探索协议/不干涉决议等修正；有三种取向（偏重洞察、研究、偏重任务）。进度满后隐藏事件 fircon.11 设置“待选洞察科技”标志并发出提示，局势随后销毁。
  The situation "Observation Insights" has a single stage (0-100): monthly progress comes from observation_post_insight (0.5 for passive observation, 1.0 for other missions, per observed civilization), modified by xenophile ethics, exploration protocol, non-interference and so on; three approaches (favor insights, study, favor mission). At completion hidden event fircon.11 sets the pending-insight-tech flag and a message, then the situation is destroyed.

## 分支与结局 Branches and outcomes

- 完成后给出一个待选择的洞察科技（选择在别处进行，此处只留标志）。
  Completion leaves a pending insight-tech choice (made elsewhere; only the flag is set here).
