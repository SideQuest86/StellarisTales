## 如何开始 How it starts

需要《遥远繁星》。帝国正在进行L星团事件链（尚未开启星团或集齐线索）时，星系中有星门或L星门的非恒星天体可能生成（2级，权重3，全局一次）。

Requires Distant Stars. While the empire runs the L-Cluster chain (cluster not opened, clues incomplete), non-star bodies in systems with a gateway or L-Gate can spawn it (level 2, weight 3, once per game).

## 剧情脉络 Story outline

distar.2045“传送门劫持者”：数千年前的苏金帝国试图用干扰光束劫持星门网络时遭到攻击，光束受损但仍对准星门安保系统。修复 → GATEWAY_INTERFERENCE（140天）→ distar.2046“苏金的启迪”：未能突破安保，但获得了星门网络运作的宝贵见解。若帝国正在进行“L星团”事件链（l_cluster_chain，需《遥远繁星》），结果增加一条线索（共需7条）；集齐时触发 distar.10904“L星门见解汇集”（另一故事）。

distar.2045 "Gateway Hijackers": thousands of years ago the Sujin Empire tried to hijack the gateway network with an interference beam and was attacked; the damaged beam is still aimed at the gateway's security. Repair → GATEWAY_INTERFERENCE (140 days) → distar.2046 "Sujin Insight": the security holds, but we learn how the network works. If the empire is running the L-Cluster event chain (l_cluster_chain, Distant Stars), the result adds one clue (7 needed); completing the count fires distar.10904 "L-Gate Insights Gathered" (a separate story).
