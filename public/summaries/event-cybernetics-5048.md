## 如何开始 How it starts

一颗带有虚拟物种人口的殖民地转手给非虚拟帝国时（on_colony_transfer，common/on_actions/00_on_actions.txt:3396），carrier 事件 cybernetics.5048 触发。

When a colony with virtual-species pops is transferred to a non-virtual empire (on_colony_transfer, common/on_actions/00_on_actions.txt:3396) the carrier event cybernetics.5048 fires.

## 剧情脉络 Story outline

单窗口“几乎无害”：几乎全由虚拟居民组成的人口冲破防火墙逃走；效果是以所有者主物种创建新的人口组，并杀死所有带虚拟物种特质的人口。选项只有“恼人的…”。

A single window "Virtually Harmless": the mostly virtual population breaks through the firewalls and escapes; the effect creates a pop group of the owner's main species and kills all pops with the virtual-species trait. The only option is a sigh.
