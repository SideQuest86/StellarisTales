## 如何开始 How it starts

无战略资源的小行星可能生成（3级，权重2，null_spawn_chance 0.5）。

Can spawn on asteroids without strategic resources (level 3, weight 2, null_spawn_chance 0.5).

## 剧情脉络 Story outline

distar.3040“外星机器”：仍能运作的机器上有一根奇怪的拉杆。拉动 → 1天后：若2–8跳内有已勘察且没有天然虫洞的星系，distar.3042“能源脉冲”在那里撕开一个虫洞（3天后 distar.3043“天然虫洞”提示），否则 distar.3041 只有能量波掠过。两者都可再拆解机器或研究它（物理+7修正）。直接拆开 → 回收部件。

distar.3040 "Alien Machine": the still-working machine has a strange lever. Pull it → one day later: if a surveyed system without a natural wormhole lies 2–8 jumps away, distar.3042 "Energy Spike" tears a wormhole open there (distar.3043 "Natural Wormhole" follows 3 days later), otherwise distar.3041 only sends out a wave of energy. Either way the machine can then be dismantled or researched (+7 physics modifier). Take it apart at once → salvage.

## 分支与结局 Branches and outcomes

拉杆结果 3041/3042 由是否存在合适星系决定，互斥。

The lever results 3041/3042 are exclusive, decided by whether a suitable system exists.
