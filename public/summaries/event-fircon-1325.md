# 艺术寻道！ / Art Finds a Way!

- 分类 Category：文明纪事 Society (C7)

## 如何开始 How it starts

- 被观测的前超光速文明的“科技进步”局势每月有 5/100 的机会运行 preftl.50（之后 1800 天冷却），从每月观测事件池中按权重抽取一个条件满足的事件；本事件权重 100。“挣脱桎梏”帝国观测原母族时使用的专用事件池中也有本事件。
  The observed pre-FTL civilization's tech-progress situation has a 5/100 monthly chance to run preftl.50 (then an 1800-day cooldown), which draws one valid event from the monthly observation pool by weight; this event has weight 100. It is also in the separate pool used when a Broken Shackles empire observes its parent civilization.
- 条件：中世纪晚期或文艺复兴时代、被动观察（或游牧中继站观察者）；每个前超光速文明一次。
  Conditions: Late Medieval or Renaissance Age, Passive Observation (or nomad waystation); once per pre-FTL civilization.
- 隐藏分派事件设置一次性标记，然后在 0–25 天后向观测哨站拥有者（及游牧中继站观察者）发出可见事件。
  The hidden dispatcher sets a once-only flag and sends the visible event to the observation post owner (and nomad waystation observers) after 0-25 days.
