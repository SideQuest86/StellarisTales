## 如何开始 How it starts

荒芜或寒冷荒芜星球可能生成（5级，权重3；需要 has_shroud_dlc；星球已有多个修正时权重为0）。生成时给星球添加 carbon_world 修正并通过 anomaly.6662 添加矿物矿藏。

Can spawn on a barren or cold barren planet (level 5, weight 3; needs has_shroud_dlc; weight 0 if the planet already has several modifiers). on_spawn adds the carbon_world modifier and a minerals deposit via anomaly.6662.
