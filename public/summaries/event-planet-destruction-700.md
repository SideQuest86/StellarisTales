# 行星已被淹没 / Planet Drenched

- 分类 Category: C8 银河轶事 / C8 Galactic miscellany · 来源 Sources: events/planet_destruction_events.txt:1877-2215; common/on_actions/01_planet_destruction.txt:124-127 · 审阅 Reviewed 2026-10-13

## 如何开始 How it starts

玩家用巨像的“洪流（Deluge）”武器毁掉/改造一颗行星时（common/on_actions/01_planet_destruction.txt:124-127），隐藏事件触发；若星球有所有者且不是自己，所有者的对手即玩家获得叙事窗口 planet_destruction.701。圣地另走 planet_destruction.607/615 一线。

When the player's Colossus fires "Deluge" at a planet (common/on_actions/01_planet_destruction.txt:124-127) the hidden dispatcher fires; if the planet has an owner that is not the firing country, a narrative window planet_destruction.701 is shown to the firing player. Holy worlds take the planet_destruction.607/615 route instead (see the holy-world story).

## 剧情脉络 Story outline

单窗口 planet_destruction.701，每个国家只显示一次（国家旗标 fired_deluge）。若星球上有观测前哨，一天后另有 planet_destruction.1000 通知；若是机械意识（Contingency）的世界则触发 crisis.2040/2046（属危机故事）。

A single window planet_destruction.701, shown once per country (country flag fired_deluge). If the planet had an observation outpost, planet_destruction.1000 follows one day later; Contingency machine worlds trigger crisis.2040/2046 (crisis stories).
