## 如何开始 How it starts

开局隐藏事件 6000 在母星附近的边缘地带生成一个隐秘的灵能国家“流亡者”及其缓冲星系，并安排 3 个月后的 6050 与 12 年后的 6125。母星上有压制灵能的远古堡场。
Hidden 6000 at game start creates a hidden psionic state, the Exiled, with a buffer system near the homeworld, and schedules 6050 (3 months) and 6125 (12 years). The homeworld has an ancient ward that suppresses psionics.

## 剧情脉络 Story outline

1. **边境调查**：6050 堡场读数异常 → 探索边境星系的任务 → 舰队进入缓冲星系 → 1 天后 6101 危险能量，与流亡者建立接触 → 首次接触 6110 → 6115 → 6120（任务中止，30 天后 6125 幻象）。之后可经外交界面联络流亡者（6020 未交谈 / 6030 交谈后）。
   **The border**: 6050 → explore the border system → a fleet enters the buffer system → 6101, contact with the Exiled → first contact 6110 → 6115 → 6120 (aborted; 6125 thirty days later). Diplomacy with the Exiled then shows 6020 (before talks) or 6030 (after).
2. **光环蔓延**：流亡者的灵能光环扩展到缓冲星系 → 6200 → 灵能辐射研究（科研船，180 天）→ 6205 → 灵能光环抗性研究（2000 社会）→ 6210 → “宏伟堡场”事件链；建成宏伟堡场 → 6215。光环若先到达母星系则有 6225。
   **The spreading aura**: the aura reaches the buffer system → 6200 → Psi-Radiation project (science ship, 180 days) → 6205 → Psionic Aura Resistance (2000 society) → 6210 → *The Grand Ward* chain; building it → 6215. If the aura reaches the home system first, 6225.
3. **虚境封印**：6215 开启封印建造事件链，并安排 25 年后的 6505。研究“灵能压制” → 6300；在边境星系建成虚境封印 → 6500。两条路都通向灵主乌克霍格拉斯·斯卡拉特的通讯（6510 或 6560）→ 6515 → 6520 → 6525 最后通牒。
   **The Shroud Seal**: 6215 opens the seal-construction chain and schedules 6505 in 25 years. Researching Psionic Suppression → 6300; building the seal in the border system → 6500. Both routes reach the Psiarch's transmission (6510 or 6560) → 6515 → 6520 → 6525, the ultimatum.
4. **灵能战争**：拒绝 → 流亡者宣战（6530）；同意 → 拆除封印（6535 → 6550），10 年后 6570 仍宣战，重建封印则 6575 立即宣战。经由 25 年计时进入的 6560 路线只能拒绝。战争事件链期间：在流亡者核心星系建封印 → 6580；夺取其第一颗星球 → 6600（攻占）或 6601（殖民）。
   **The psionic war**: refusing → war (6530); agreeing → the seal is dismantled (6535 → 6550), war comes after 10 years (6570) or at once if the seal is rebuilt (6575). The 25-year route via 6560 can only refuse. During the war chain: a seal in the Exiled core → 6580; the first of their two worlds → 6600 (invasion) or 6601 (colonisation).
5. **梦客圣所**：取得第二颗星球 → 6700 圣所中的茧 → 研究（5000 物理）→ 6710 → 6720 茧中之声（可循环问答，“转轮”回答解锁最后两个选项）→ 6770 梦客：摧毁它（能量与修正）或利用它（遗珍“失落的庇护者”；启用遗珍 → 6780–6795）。若第二颗星球被炸毁 → 6705。
   **The Sanctum of the Dreamer**: the second world → 6700 → research (5000 physics) → 6710 → 6720 (looping questions; the wheel answer unlocks the last two) → 6770: destroy it or harness it (relic *The Lost Patron*; activating it → 6780–6795). If the second world is destroyed instead → 6705.
6. **第一城邦**：6770 或 6705 两年后 6800 → 以一支舰队建立灵督城邦 → 6825（支付能量/食物、合金、影响力）→ 城邦首次问候（服务菜单）→ 关闭后 6830。之后城邦按局势进度分红（6841–6844，随机32/32/32/4）。
   **The first enclave**: two years after 6770 or 6705, 6800 → found an enclave with a fleet → 6825 → the enclave's first greeting (service menu) → 6830 on closing. Afterwards the enclave pays dividends (6841–6844, random 32/32/32/4).

## 分支与结局 Branches and outcomes

- 母星被攻占（尚未建成宏伟堡场时）→ 6231 夺回母星事件链 → 夺回后 6241，并按剩余时间重新安排战争计时。
  If the homeworld falls before the Grand Ward → 6231 reclaim chain → 6241 on recapture, with the war timers re-scheduled.
- 流亡者被任何势力消灭时，所有相关事件链与项目终止（隐藏事件 6546）。 If the Exiled are destroyed by anyone, all related chains and projects end (hidden 6546).
- 结局：灵督城邦建立（6830）；城邦服务与分红为持续机制。 Ending: the enclave stands (6830); services and dividends continue.

## 条件与文明差异 Conditions and variants

- 许多窗口按是否已到过边境、舰船是否在场、是否已与流亡者交谈而换文本（6101、6200、6205、6215、6225、6700、6705）。
  Many windows change text by whether the border was visited, a ship was present, or the Exiled were spoken to.
- 城邦服务菜单（雇佣舰队、升级、科技）是所有联络灵督城邦的帝国共用的重复菜单，作为独立故事链接（`event-shroud-4201`）。
  The enclave service menu is a repeatable menu shared by every empire contacting a Mindwarden enclave; it is a separate linked story.
