# 无法扫描的物体 / Unscannable Object

- 分类 Category：深空异闻 Exploration · DLC：《遥远繁星》Distant Stars（has_distar）

## 如何开始 How it starts

需要《遥远繁星》。小行星可能生成（1级，权重1，每个帝国一次）。

Requires Distant Stars. Can spawn on asteroids (level 1, weight 1, once per empire).

## 剧情脉络 Story outline

distar.270“深奥的多面体”：回收的多面体能反射低频能量束，表面刻有似与虫洞度量有关的科学记号，用途与来源仍是谜。奖励物理学研究，记录标本 sonic_reflective_prism。若帝国正在进行“L星团”事件链（l_cluster_chain，需《遥远繁星》），结果增加一条线索（共需7条）；集齐时触发 distar.10904“L星门见解汇集”（另一故事）。30天后的通用接触报告 story.5 是共享事件，不属于本故事。

distar.270 "Puzzling Polygon": the recovered polygon reflects low-frequency energy beams and is engraved with notation that seems to concern wormhole metrics; its purpose and origin remain unknown. Rewards physics research; specimen sonic_reflective_prism. If the empire is running the L-Cluster event chain (l_cluster_chain, Distant Stars), the result adds one clue (7 needed); completing the count fires distar.10904 "L-Gate Insights Gathered" (a separate story). The generic contact report story.5 30 days later is a shared helper, not part of this story.

## 分支与结局 Branches and outcomes

Single outcome; no random branch.
