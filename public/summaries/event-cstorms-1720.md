# 鬼影重重 / Ghostly Apparitions

- 分类 Category：C8 银河轶事 / C8 Galactic miscellany · DLC: Cosmic Storms

## 如何开始 How it starts

虚境风暴离开拥有殖民地的星系时（00_on_actions.txt:5434），非机器帝国的隐藏事件 cstorms.1720 有75%概率排程 cstorms.1725（90天后）。

When a shroud storm leaves a system with a colony (00_on_actions.txt:5434) hidden cstorms.1720 (not for machine empires) has a 75% chance of scheduling cstorms.1725 (after 90 days).

Option a (spiritualists with 100 minerals only): pay minerals for unity; the other option "Fascinating": the planet gets the d_ghostly_canyon deposit.
