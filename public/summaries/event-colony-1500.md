## 如何开始 How it starts

- 殖民地2岁（3/958）或3岁（2/739）时的随机事件；星球需有卫星，非栖息地/方舟，非荒野帝国；每个帝国一次（FLDrone_country）。
  Random colony event at age 2 (3/958) or 3 (2/739); the planet needs a moon, no habitat/ark, non-wilderness empire; once per empire (FLDrone_country).

## 剧情脉络 Story outline

- 1500「序曲」：启用“遗留者”项目 → 1501「发现」：揭示古老无人机。
  1500 "A Prelude": enables the "Left Behind" project -> 1501 "Discovery" reveals the ancient drones.
- 1501 之后每个事件相隔360天（部分带随机60天）：1502 觉醒（若有障碍则清除一个）→ 1503 → 1504 → 1505 → 1506 → 1507 → 1508 → 1509 → 1510「答案在天上」。
  After 1501 each event follows 360 days later (some with random 60): 1502 awakening (clears a blocker if present) -> 1503 -> 1504 -> 1505 -> 1506 -> 1507 -> 1508 -> 1509 -> 1510 "Answers Above".
- 1510 的三个选项决定海盗的强度：a 原样（720天后 1514）；b 削弱（7天后 1511「告别」→ 700天后 1512）；c 加强（720天后 1513）。
  The three 1510 options set the pirates' strength: a unmodified (1514 after 720 days); b weakened (1511 after 7 days -> 1512 after 700); c strengthened (1513 after 720).

## 分支与结局 Branches and outcomes

- 三种结局互斥，均以一支敌对海盗舰队出现在殖民地收尾。
  The three endings are exclusive; each ends with a hostile pirate fleet appearing at the colony.

## 条件与文明差异 Conditions and variants

- 1502 仅当星球有障碍时出现，否则跳过。
  1502 appears only if the planet has a blocker; otherwise it is skipped.
