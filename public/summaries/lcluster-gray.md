# 小灰 / Gray

- 分类 Category：探索 Exploration

## 如何开始 How it starts

- 只在开局随机得到“空星团”（没有风暴、龙季、德萨努标记）时：异常 `disco_gray_cat`（地表信号，等级 3）可出现在 L 星团的灰蛊星球上（权重 +6）；完成后 `graygoo.400`。
  Only in the empty-cluster outcome (no storms, dragon season or Dessanu markers) does the anomaly `disco_gray_cat` (surface signal, level 3) spawn on gray-goo planets in the L-Cluster (weight +6); on completion, `graygoo.400`.

## 剧情脉络 Story outline

- 400「安静散步」→ 401-406 一段单线对话（401 有三个选项，其中后两个回到 402）；406 的隐藏选项 c（邀请加入）触发隐藏的 `graygoo.499` 创建小灰国家。
  400 "Quiet Stroll" -> a single-thread dialogue 401–406 (401 has three options, of which the last two return to 402); the hidden option c in 406 (invite to join) triggers the hidden `graygoo.499`, which creates the Gray country.
- 之后的通讯菜单为可重复的 500（初始）及 501（行政官）、502（战舰）、503（地面单位）、504（重组中），每次只出现与当前状态对应的一个。
  Afterwards the communication menu offers the repeatable 500 (initial) and 501 (administrator), 502 (warship), 503 (ground unit) and 504 (reorganizing); each time, only the one matching the current state appears.
- 小灰被击溃或解散时（隐藏的 510，每月检查）：511 通知，3600 天后 512 恢复。
  When Gray is crushed or dissolved (hidden 510, checked monthly): 511 notifies, and 512 restores it after 3600 days.

## 分支与结局 Branches and outcomes

- 没有终局；小灰可在行政官、战舰、地面部队之间切换。
  There is no final ending; Gray can switch between administrator, warship and ground force.
- `graygoo.550`「诡异的宁静」是空星团中首次进入星系时的独立氛围事件，与小灰的相遇无直接联系。
  `graygoo.550` "Eerie Calm" is a standalone atmosphere event on first entering a system in the empty cluster and has no direct link to meeting Gray.
