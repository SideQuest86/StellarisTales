## 如何开始 How it starts

起源卡片：这个文明刚从同化他们的机器网络中被切断，在母星上醒来，正与追杀他们的机械舰队交战。开局时游戏生成敌对的机械帝国“奥普斯累积者”和遥远的机械核心星系（`01_start_of_game_effects.txt:4651`），隐藏事件 199 在首都星系放置一支敌对机械舰队。击毁它 → 100“胜利属于我们”。
The card: the civilisation has just been cut off from the machine network that assimilated them and wakes fighting its hunter fleets. At start the game creates the hostile machine empire (the Opus Accumulator) and a distant machine core; hidden 199 places a hostile fleet over the capital. Destroying it → 100 *Victory is Ours*.

## 剧情脉络 Story outline

1. **摇篮废墟**：100 在本星系的前超光速星球上开启五阶段考古 3300 → 3320，最终揭示：毁灭这个文明的正是被机器驱使的自己；最后的选择会推动身份局势。
   **The Ruined Cradle**: 100 opens a five-stage dig on the pre-FTL world of the home system (3300 → 3320); its last chapter reveals that the dead civilisation was destroyed by the empire itself under machine control.
2. **机械遗产（五个星系）**：100 之后 100–120 天，2000 收到信号，开启“机械遗产”事件链。
   **The Machine Legacy (five systems)**: 100–120 days after 100, 2000 receives a signal and opens the *Machine Legacy* chain.
   - 工厂：勘察 → 异常 → 2005 → 遗址 2010 → 2015 → 第三阶段二选一（2021 保留武器设计 / 2022）→ 15 天后 2030 敌舰出动 → 击毁（2036 本帝国 / 2037 他国）或 4 年后仍在（2038），都指向下一个世界。2010 的 b 选项可提前开启身份局势（3000）。
     The Makers: survey → anomaly → 2005 → dig 2010 → 2015 → stage 3 one of two (2021 / 2022) → 2030 a hostile fleet 15 days later → destroyed (2036 you / 2037 another) or still active after 4 years (2038); all point to the next world. Option b of 2010 can start the identity situation early (3000).
   - 被同化者：勘察 → 90 天项目 → 2100 → 遗址 2110 → 2115 → 第三阶段二选一（表达悔意 → 2125 并引出 3100“移除的理由”；否则 2121）→ 2130 指向创造者世界。
     The Taken: survey → 90-day project → 2100 → dig 2110 → 2115 → stage 3 one of two (regret → 2125, which brings 3100 *Grounds for Removal*; otherwise 2121) → 2130 points to the Creators.
   - 创造者：勘察 → 90 天项目 → 2200（可不发掘）→ 遗址 2210 → 2215。首次进入该星系 360 天后 2205 发现故乡金库信号。
     The Creators: survey → 90-day project → 2200 (digging is optional) → dig 2210 → 2215. 360 days after first entering that system, 2205 finds the vault signal.
   - 故乡（发源地）：舰队进入 → 2300 → 金库信标项目 → 2305：开启故乡遗址（2310 → 2315 → 第三阶段二选一 2321/2325 → 2330），同时派出拦截舰队；击毁它 → 2390 指向机械核心。
     The homeworld (Point of Origin): enter → 2300 → vault beacon project → 2305 opens the homeworld dig (2310 → 2315 → 2321/2325 → 2330) and sends an intercept fleet; destroying it → 2390 marks the machine core.
   - 机械核心：击毁奥普斯哨兵 → 2401（本帝国）/ 2402（他国）→ 2405 与“奥普斯之核”残存意识对话 → 2410 → 2415 → 2420 → 机械残骸研究（360 天；25/50/75% 时按已完成的遗址出现 2425/2430/2435）→ 2440 → 2445 创造者留下的终端。
     The machine core: destroying the Opus Sentinel → 2401 (you) / 2402 (another) → 2405 the dying Nexus → 2410 → 2415 → 2420 → the Machine Husk study (360 days; at 25/50/75% the archives 2425/2430/2435 for completed sites) → 2440 → 2445, a terminal left by the Creators.
3. **具现身份局势**：由 2010.b、3100（90 天后）或十年检查（已有派系时）开启。初始进度 50；每 1800–1920 天按所在阶段走一步：去义体化（3105 → 3106 → 3107）、维持现状（3115 → 3116 → 3117）、义体化（3110 → 3111 → 3112）；先走完的一条路线以 3090 结束局势。去义体化步骤之后可能出现随机后果 5001–5004（各一次）。
   **The Embodied Identity situation**: started by 2010.b, by 3100 (+90 days) or by the decade check once factions exist. It starts at 50; every 1800–1920 days it takes a step of the track matching its stage — decyberize (3105 → 3106 → 3107), status quo (3115 → 3116 → 3117), cyberize (3110 → 3111 → 3112); the first track completed ends it with 3090. Decyberization steps may bring one of the random follow-ups 5001–5004 (each once).

## 分支与结局 Branches and outcomes

- 2445 中：选项 b（需合成进化，或局势结束后主要物种仍保有最高级的正面义体特质）与 c 都通向 2446 创造者的恳求 → 2450“机械万岁”，继承机械王座；选项 d 启动装置 → 2455“重生”，机械世界改造为盖亚星球。两者都结束事件链。
  At 2445, option b (Synthetic Evolution, or the main species still has the top positive cybernetic trait after the situation) and option c lead to 2446, the Creators' plea → 2450 *Long Live the Machine*; option d uses the device → 2455 *Rebirth*, the machine world becomes a Gaia world. Both end the chain.
- 身份局势结局 3090：三条路线中最先完成的一条。 Identity situation ending 3090: whichever track completes first.

## 条件与文明差异 Conditions and variants

- 外交插曲：与畏惧本帝国的文明建立通讯时 3205（仅一次）；首次与机械帝国通讯时 3250（非同化者）或 3255（同化者）。尚无派系时，每年有机会出现 3205/3005/3010/3100 之后的派系提示 4005。
  Diplomacy: 3205 on first contact with an empire that fears you (once); 3250/3255 on first communications with a machine empire. While no factions exist, a yearly check may bring 4005.
- 其他帝国视角：非本起源的帝国勘察这些世界时看到异常 MACHINE_LEGACY_*（2006、2105、2200 的他国选项），击毁哨兵时看到 2403 → 2411；均与本起源对应窗口并列。
  Other empires surveying these worlds see anomaly variants (2006, 2105, the other options of 2200) and, after destroying the Sentinel, 2403 → 2411; they sit next to the origin's own windows.
