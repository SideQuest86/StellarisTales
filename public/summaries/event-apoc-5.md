# 天然虫洞 / Natural Wormhole

- 分类 Category：C8 银河轶事 / Galactic miscellany
- DLC：Apocalypse

## 如何开始 How it starts

飞船首次进入有天然虫洞的星系（排除虚境隧道枢纽/节点、无形系统、晶体球系统），且本国尚未遇到虫洞（encountered_first_wormhole）时触发 apoc.5。

A ship first entering a system with a natural wormhole (excluding Shroud tunnel nexus/node, formless and crystal-sphere systems), when the empire has not met a wormhole (encountered_first_wormhole), triggers apoc.5.

## 剧情脉络 Story outline

单窗口通知，设下 encountered_first_wormhole 并让本国“看过”虫洞类型；唯一选项“如果我们能将其稳定的话……”。

A single notification that sets encountered_first_wormhole and marks the wormhole bypass type as seen; its only option is "If only we could stabilise it...".
