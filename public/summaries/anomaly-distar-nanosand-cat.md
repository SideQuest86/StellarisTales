# 金属沙子 / Metallic Sands

- 分类 Category：深空异闻 Exploration · DLC：《遥远繁星》Distant Stars（has_distar） · 审阅 Reviewed：2026-10-12（已审阅 reviewed）

## 如何开始 How it starts

需要《遥远繁星》。沙漠、盖亚或无战略资源的荒芜星球可能生成（2级，权重1，每个帝国一次）。

Requires Distant Stars. Can spawn on desert, Gaia or (without strategic resources) barren planets (level 2, weight 1, once per empire).

## 剧情脉络 Story outline

distar.280“纳米沙子”：沙丘几乎全由数百万年前的破碎纳米机器人构成，科学官推测它们曾用于改造这颗星球。宜居星球获得纳米沙矿藏，否则获得矿物矿藏；奖励工程学研究和200纳米机器人。若帝国正在进行“L星团”事件链（l_cluster_chain，需《遥远繁星》），结果增加一条线索（共需7条）；集齐时触发 distar.10904“L星门见解汇集”（另一故事）。30天后的通用接触报告 story.5 是共享事件，不属于本故事。

distar.280 "Nanosand": the dunes are almost entirely broken nanites millions of years old, perhaps once used to terraform the planet. Habitable planets gain a nanosands deposit, others a minerals deposit; rewards engineering research and 200 nanites. If the empire is running the L-Cluster event chain (l_cluster_chain, Distant Stars), the result adds one clue (7 needed); completing the count fires distar.10904 "L-Gate Insights Gathered" (a separate story). The generic contact report story.5 30 days later is a shared helper, not part of this story.

## 分支与结局 Branches and outcomes

唯一结果，无随机分支。

Single outcome; no random branch.

## 条件与文明差异 Conditions and variants

排外帝国只有“令人不安”选项，没有纳米机器人奖励。事件图片随星球类型（沙漠/盖亚/荒芜）变化。

Xenophobes only get "Disconcerting" without the nanites. The picture changes with planet class (desert/Gaia/barren).
