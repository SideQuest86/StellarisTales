## 剧情脉络 Story outline

- 殖民：5007a→项目GAS_GIANT_COLONY→5008（设new_baldarak_settled）。之后三条互相独立的线：  
  Colony: 5007 a → project GAS_GIANT_COLONY → 5008 (sets new_baldarak_settled). Three independent lines then follow:
- ① 切布基·拉德：5009（~220个月）b→项目GAS_GIANT_LOST_CHABKY→5010（设chabky_raddh_done）→5011“失联”（~120个月；a→项目GAS_GIANT_LOST_CONTACT→5012“特别项目完成”→5013“革命阵线”；b不管）。  
  ① Chabky Raddh: 5009 (~220 months) b → project GAS_GIANT_LOST_CHABKY → 5010 (sets chabky_raddh_done) → 5011 "Lost Contact" (~120 months; a → project GAS_GIANT_LOST_CONTACT → 5012 → 5013 "Revolutionary Front"; b ignores it).
- ② 5013三选：a对话；b运送突击队→项目GAS_GIANT_REVOLT→5015→5016“革命议会”（35-75天，设baldarak_revolution_1）→5017→5018→5019（每约120个月，公布星球改名等）；c不介入→5014“巴尔达拉克回应”（35-75天）a→项目GAS_GIANT_OCCUPATION→5020→5021（设new_baldarak_occupation_1）→5022→5023→5024（每约120个月的占领公告）。  
  ② 5013 offers three options: a dialogue; b ferry the commandos → project GAS_GIANT_REVOLT → 5015 → 5016 "Revolutionary Council" (35-75 days, sets baldarak_revolution_1) → 5017 → 5018 → 5019 (each ~120 months: public announcements, planet renamed); c stay out → 5014 "Baldarak Responds" (35-75 days) a → project GAS_GIANT_OCCUPATION → 5020 → 5021 (sets new_baldarak_occupation_1) → 5022 → 5023 → 5024 (occupation announcements every ~120 months).
- ③ 5025“科学院”与5026“春季大扫除”：新殖民地定居后约每320个月各一次，仅在尚未失联时出现（给物理研究/矿物奖励）。  
  ③ 5025 "Baldarak Science Academy" and 5026 "Spring Cleaning": about once per 320 months each after settlement, only while contact is not lost (physics research / minerals reward).

## 分支与结局 Branches and outcomes

- 革命线与占领线由5013的选项互斥；革命线5017/5018中选“屏蔽”(dathnak_blocked)会终止后续公告，占领线的屏蔽选项无效。  
  The revolution and occupation lines are exclusive via 5013; choosing to block (dathnak_blocked) in 5017/5018 stops the later announcements of the revolution line, but the block option has no effect on the occupation line.
