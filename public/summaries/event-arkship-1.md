# 漂泊者与定居者 / Drifters and Settlers

## 如何开始 How it starts

方舟舰事件调度 arkship.1 调用 nomads.7000；非杀戮型、已遇见其他物种的帝国（格式塔仅限机仆或永恒航行）若尚无迁徙说明标记，收到 nomads.7005。

The arkship event dispatcher arkship.1 calls nomads.7000; a non-homicidal empire that has met other species (gestalts only if Rogue Servitor or Forever Cruise) without the migration-information flag receives nomads.7005.

## 剧情脉络 Story outline

说明游牧民与定居者之间的人口迁徙。

It explains population migration between drifters and settlers.

## 分支与结局 Branches and outcomes

三个选项决定对迁徙的态度（亲外与排外各受限制）。

Three options set the stance on migration (restricted for xenophiles and xenophobes respectively).
