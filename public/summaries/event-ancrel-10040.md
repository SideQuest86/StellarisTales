# 特殊项目解锁 / Special Project Unlocked

- 分类 Category：先驱者与考古 Precursors · DLC：《远古遗物》Ancient Relics

## 如何开始 How it starts

九条经典先驱者的“秘密研究”稀有文物行动（artifact_irassian_research、yuht、inetian、adakkaria、vultaum、cybrex、league、baol、zroni，common/artifact_actions/artifact_actions.txt:582–838）执行后，都会触发这条共用通知 ancrel.10040。

Each of the nine "secrets research" artifact actions of the classic precursors (irassian, yuht, inetian, adakkaria, vultaum, cybrex, league, baol, zroni; common/artifact_actions/artifact_actions.txt:582-838) fires this shared notification ancrel.10040 when run.

## 剧情脉络 Story outline

“我们的科学家已开始一项特殊项目，研究先驱者更深的秘密。”单一选项“知道了”。真正的项目（如 VULTAUM_SECRETS 等）由各先驱者的故事讲述。

"Our scientists have begun a special project to study the deeper secrets of the precursors." A single "Acknowledged" option. The real projects (VULTAUM_SECRETS and the rest) are told in each precursor's own story.
