# 星河卫士 / Defender of the Galaxy

- 分类 Category：天灾（玩家天灾路线）Crisis (player crisis path)

## 如何开始 How it starts

选择“星河卫士”路线后第一级解锁，收到“银河守卫”（ambition.100），开启事件链与第一项项目“量身外交”，并获得加入银河共同体的任务。天灾货币为“诚信”。
After choosing the "Defender of the Galaxy" route, level 1 unlocks; you receive "Galactic Guardian" (ambition.100), which opens the event chain and the first project "Tailored Diplomacy", along with a task to join the Galactic Community. The crisis currency is "Integrity".

## 剧情脉络 Story outline

1. **等级**：二级（项目一完成、共同体成员、2000）→“无尽的职责”，开启项目二“灵感源泉”；三级（项目二完成、议会成员、6000）→“自由的象征”；四级（成为银河监管人、18000）→“誓约守护者”，开启项目四“主动出击”；五级（银河中存在天灾或第五级玩家天灾、仍为监管人、45000）→“星河卫士”，开启结局事件链“先发制人”。
   **Levels**: level 2 (project one completed, Community member, 2000) -> "Endless Duty", which opens project two "Wellspring of Inspiration"; level 3 (project two completed, Council member, 6000) -> "Symbol of Freedom"; level 4 (becoming Galactic Custodian, 18000) -> "Oath Keeper", which opens project four "Take the Initiative"; level 5 (a crisis exists in the galaxy or a level-5 player crisis exists, still Custodian, 45000) -> "Defender of the Galaxy", which opens the ending chain "Strike First".
2. **主动召来天灾**：项目四完成后30–60天，从尚未发生的终局天灾（索林原虫、破界者、肃正协议、合成女王）中随机召来一场（“暗影潜伏”135）；若发生过的天灾少于两场，再开启项目五“先发制人”召来第二场（“坏事成双”140）。若完成前已有天灾发生，项目四会被取消但仍视为完成。
   **Summoning crises on purpose**: 30–60 days after project four is completed, one of the endgame crises that has not yet occurred (Prethoryn, The Unbidden, Purity Protocol, Synthetic Queen) is summoned at random ("Lurking Shadow", 135); if fewer than two crises have occurred, project five "Strike First" opens to summon a second ("Trouble Comes in Pairs", 140). If a crisis has already occurred before project four is finished, project four is cancelled but still counts as completed.
3. **圣骑士**：第四级天赋后，身为监管人可通过“圣骑士计划”决议（需银河防卫军）→ 圣骑士舰项目 → 建舰时提名圣骑士、确认职业；决议还可改为“直接指挥”或解散计划。
   **Paladins**: after the level-4 perk, as Custodian you can pass the "Paladin Program" resolution (requires the Galactic Defense Force) -> Paladin ship project -> when the ship is built, nominate a Paladin and confirm the class; the resolution can also be changed to "Direct Command" or the program can be disbanded.
4. **胜利**：击败至少两场终局天灾且无存活天灾后，监管人任期结束或主动卸任，5天后“最终的和平”（325），赢得游戏。
   **Victory**: after defeating at least two endgame crises with no crisis still alive, the Custodian's term ends or they step down voluntarily; 5 days later "Lasting Peace" (325) wins the game.

## 分支与结局 Branches and outcomes

- 胜利：325。没有失败结局事件。
  Victory: 325. There is no defeat ending event.
- 召来的天灾链接到各自档案：索林原虫、破界者、肃正协议、塞塔娜。
  Summoned crises link to their own archives: Prethoryn, The Unbidden, Purity Protocol, Setana.

## 条件与文明差异 Conditions and variants

- 每场终局天灾的胜利事件在你持有“先发制人”事件链时都会为其计数（交叉条件，见各天灾档案）。
  Each endgame crisis's victory event counts toward it while you hold the "Strike First" event chain (cross-condition; see each crisis archive).
